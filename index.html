Como funcionam os modelos de linguagem?

Os modelos de linguagem utilizam tokens para processar informações. Cada pergunta enviada e cada resposta recebida consome recursos computacionais.

1. Configurando GuardRails

GuardRails são instruções e regras que orientam o comportamento de um assistente de inteligência artificial.

Exemplo de instruções:

instructions = """
Você é um mentor de carreiras.

- Responda com educação.
- Ajude com orientação profissional.
- Não forneça informações perigosas.
- Não solicite senhas ou dados pessoais.
- Seja claro e objetivo.
"""

Teste o comportamento do assistente:

A resposta aparecerá aqui.

2. Entendendo os Tokens

Tokens são unidades utilizadas pelos modelos de linguagem para processar textos. Uma palavra pode representar um ou mais tokens.

Input

Tokens enviados pelo usuário e pelas instruções.

Output

Tokens utilizados na resposta gerada pela IA.

Total

Soma dos tokens de entrada e saída.

Total de tokens = Input + Output

3. Calculadora de Tokens e Custos

Simule o consumo de tokens e estime o custo de uma interação com uma API de inteligência artificial.

Resultado da simulação

Tokens de entrada: 0

Tokens de saída: 0

Total de tokens: 0

Custo de entrada: US$ 0,00

Custo de saída: US$ 0,00

Custo total: US$ 0,00

Simulação educativa. Os preços são exemplos editáveis e não representam necessariamente os preços atuais de qualquer provedor.

4. Monitorando o uso da API

Podemos utilizar o objeto response.usage para acompanhar o consumo de tokens de uma requisição. 

print(f"Tokens de entrada: {response.usage.input_tokens}")
print(f"Tokens de saída: {response.usage.output_tokens}")
print(f"Total de tokens: {response.usage.total_tokens}")

Os nomes dos campos podem variar conforme a API e o SDK utilizado.

5. Segurança e Privacidade

É importante proteger nossos dados pessoais ao utilizar ferramentas de inteligência artificial.

  • Não compartilhe senhas.
  • Não informe números de CPF.
  • Evite enviar endereços pessoais.
  • Não compartilhe informações bancárias.
  • Verifique as políticas de privacidade do provedor.
Atenção!

GuardRails ajudam a orientar o comportamento da IA, mas não garantem segurança absoluta nem substituem controles de privacidade e proteção de dados.
